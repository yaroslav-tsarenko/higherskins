# Higherskins — Вимоги до сайту

Загальний перелік вимог до сайту, згрупований за розділами. Кожен пункт
сформульовано як вимогу з коротким критерієм приймання. Позначка `[x]` — вимогу
реалізовано.

---

## Загальне

- [x] **Коректні реквізити компанії.** Скрізь (політики, футер, сторінки About/Contact,
  листи) вказано: `HIGHER MARGINS LTD`, Company No. `15605091`,
  `20 Wenlock Road, London, England, N1 7GU`, `info@higherskins.com`.
- [x] **Поповнення гаманця/балансу.** Користувач має змогу поповнити баланс
  акаунта; кошти зараховуються на гаманець і доступні для покупок.
- [x] **Прибрати слово «Marketplace».** Термін не зустрічається в UI сайту.
- [x] **Фільтр категорій у хедері.** При послідовному виборі категорій (напр.
  Knives → Gloves) відображається саме остання обрана категорія, і вона збігається
  з тим, що у URL. _(див. screen1)_
- [x] **Розділені бази даних / унікальність email.** Реєстрація з новою поштою
  не повертає помилку «вже існує», якщо користувач раніше не реєструвався; dev і
  prod використовують окремі БД.
- [x] **Лист підтвердження після реєстрації.** Після створення акаунта користувач
  отримує вітальний лист на пошту.
- [x] **Лист відновлення пароля.** За запитом на зміну пароля надсилається лист
  з посиланням для відновлення (токен дійсний 1 година).
- [x] **Steam-логін не показує Vercel URL.** Під час входу через Steam
  відображається доменний URL сайту, а не службовий URL Vercel. _(див. screen2)_
- [x] **Прибрати блоки про продаж скінів користувачами.** Такого функціоналу немає,
  тому всі заяви/блоки/тексти про користувацький продаж скінів видалені.
